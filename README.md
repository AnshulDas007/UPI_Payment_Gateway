# Centralized UPI Payment Gateway

> **Cryptography (BITS F463) — Term Project**

A secure UPI (Unified Payments Interface) payment gateway simulation integrating **Blockchain**, **SHA-256**, **Lightweight Cryptography (SPECK Cipher)**, and **Quantum Cryptography (Shor's Algorithm)** to demonstrate modern and post-quantum security concepts in digital payment systems.

---

## Features

| Feature | Technology | Description |
|---|---|---|
| **ID Generation** | SHA-256 | 16-hex-digit MID, UID, MMID derived from SHA-256 hashes |
| **Merchant Encryption** | SPECK64/128 (LWC) | Merchant ID encrypted into VMID for QR codes |
| **QR Code Payments** | qrcode + Pillow | QR code generation with encrypted merchant data |
| **Transaction Ledger** | Blockchain | Immutable, hash-chained transaction records |
| **Quantum Vulnerability** | Shor's Algorithm | Demonstrates RSA weakness against quantum computing |
| **Network Simulation** | Socket Programming | Multi-device communication via TCP sockets |

## How to Run

### Step 1 — Start the Bank Server
```bash
python UPI_payment_gateway/bank.py
```
- Registers sample merchants and users automatically
- Use the interactive menu to manage accounts or press **6** to start the server on **port 9000**

### Step 2 — Start the UPI Machine
```bash
python UPI_payment_gateway/upi_machine.py
```
- Enter a registered Merchant ID (MID)
- The MID is encrypted using SPECK64/128 → VMID
- A QR code image is generated and saved
- Server starts on **port 8000**, waiting for users

### Step 3 — Run the User Client
```bash
python UPI_payment_gateway/user.py
```
- Enter the scanned VMID (from the QR code)
- Enter your MMID, transaction amount, and UPI PIN
- The transaction is processed and the result is displayed

### Quantum Demo (Standalone)
```bash
python Quantum_Demo/shor_simulation.py
```
- Demonstrates RSA vulnerability by factoring the modulus using Shor's Algorithm
- Shows how a quantum computer could recover encrypted PINs and MMIDs

## Security Technologies

### SHA-256 (ID Generation)
All IDs (MID, UID, MMID) are generated by SHA-256 hashing registration data and truncating to 16 hex digits, ensuring uniqueness and collision resistance.

### SPECK64/128 (Lightweight Cryptography)
The SPECK cipher encrypts Merchant IDs into Virtual Merchant IDs (VMIDs) embedded in QR codes. SPECK is a lightweight block cipher designed for high-speed encryption in resource-constrained environments, using 27 rounds on a 64-bit block with a 128-bit key.

### Blockchain Ledger
Every valid transaction is recorded as a block containing: Transaction ID (SHA-256 hash), previous block hash, timestamp, and transaction details. The chain is immutable — any tampering invalidates subsequent hashes.

### Shor's Algorithm (Quantum Vulnerability)
A standalone module demonstrates how Shor's Algorithm can factor RSA moduli, recover private keys, and decrypt sensitive data — highlighting the need for quantum-resistant cryptography in payment systems.
